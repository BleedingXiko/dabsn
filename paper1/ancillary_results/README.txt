Ancillary result tables for:

One Layer, Both Gaps: A Persistent-Modulation Recurrence that Generalizes Copy
and Tracks Non-Solvable Group State

Included files:

- copy_length.csv
  Three-seed copy length-generalization stress table used for the copy headline
  and Table 1 / Table 5.

- mqar_length.csv
  Three-seed MQAR length-generalization stress table used for the verified
  supporting recall result.

- keyvalue_length.csv
  Three-seed key-value length-generalization stress table used for the verified
  supporting key-value result.

- ablation_knockout.csv
  Eval-time pathway knockout table used for the copy mechanism ablation
  (copy rows). Additional rows from a separate smaller state-tracking probe are
  retained as raw experimental record but are not used in the paper.

- a5_word_results.csv
  Standard A5/60 word-problem length-generalization table used for the paper-1
  state-tracking headline (Figure 1 right panel and Figure 2).

- a5_seed1_linear_ablation.csv
  Second-seed A5/60 run plus the linear-state (input-controlled, TC0) ablation
  of the same block, used for the two-seed reproduction and the causal
  nonlinear-state mechanism result (Figure 2, Table 2).

- headline_results_paper1.csv
  Paper-1 headline rows collected in one machine-readable table.

These machine-readable tables accompany the paper source in the parent
directory. Runnable reproduction entry points are packaged under
dabsn.reproductions and installed as dabsn-reproduce-* commands.
